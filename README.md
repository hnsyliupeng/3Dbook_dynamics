# Gyroid Truss Lab

交互式 H = 12 Gyroid 双层桁架研究原型。运行 `npm install` 然后 `npm run dev`；运行 `npm test` 验证曲面约束和周期线段分解。

## 与论文的关系及限制

Dotera & Yamamoto, *Hexagulation numbers: symmetry breaking on the gyroid surface*, Interface Focus 16, 20250098 (2026), DOI: [10.1098/rsfs.2025.0098](https://doi.org/10.1098/rsfs.2025.0098)，图 4，及补充材料表 S1/S2。论文双层 H=12，每层 192 个球；同层杆件红/蓝，跨层杆件白色。论文用硬球蒙特卡洛方法获得双层构型；层约束是 `|g±(r)|<0.1`，并非精确等值面，w 是等值偏移参数而不是法向距离。

**本项目是近似研究原型，不是图 4 的定量复现。** 所附表 S2 的坐标是单层构型的 Wyckoff 代表点，不包含双层模拟的全部坐标或连杆。这里用 I-43d 的 48 个操作展开四个 H12 代表点，投影到 `g=+w`，反演得到 `g=-w` 层；以 0.158 个单胞边长作为同层距离阈值，跨层取每个红节点最近的三个蓝节点。为消除单胞边界悬空端，在三对周期面上用 marching squares 近似提取两层等值面的交线作为边界框架；跨边界的同层杆件被分割，并将交点连接到该面最近的交线节点。这个边界框架与连接杆是额外的工程构造，并非论文公开的连杆。其切分节点位于原始直杆的面交点，不保证精确落在等值面上；连接到离散曲线存在短接杆。阈值和连接规则是模型假设，没有证明图 4 的结构或对称性被重现。投影也不保证单独每层保持 I-43d。应用没有进行硬球模拟、刚度矩阵求秩或有限元分析；提供固定单胞铰接轴向杆系的机构计数下界。

## 周期性和检查

坐标为单胞分数坐标 `[0,1)`；每条无向边 `(a,b,o)` 表示从 a 到 b 的周期像 `b+o`，其中 o 是整数平移。可导出 JSON，重建无限周期图不依赖画面裁剪。显示时复制周期图并用单胞平面裁切可见几何，边界截面相互匹配。曲面使用相同周期坐标和可视窗口（`sin(2πx) cos(2πy) + sin(2πy) cos(2πz) + sin(2πz) cos(2πx) = 0`，是论文使用的 Gyroid 近似，并非精确最小曲面）。

界面计算原始球心的等值面残差、周期线段分段长度误差、两层图连通分量及度为 1 的节点数量、周期像下红蓝同层杆件（含边界杆与短接杆）的最小胶囊净距（中心线距离减两倍杆半径）。它**不检查白色连接杆彼此及其与其他非端点杆件的干涉，也不检查节点实体、力学稳定性或球体打包**；净距不是生产设计的认证。边界显示截断仅用于渲染，模型仍保留跨边界边和偏移。结果取决于 w 和杆径。

Three.js 0.170.0 is vendored under its MIT license (see `apps/gyroid-truss/vendor/THREE-LICENSE.txt`). The supplied figure is displayed for comparison with attribution to the paper (CC BY 4.0).

边界轮廓是每个偏置层 `g=±w` 与单胞面的交线，不是中央参考面 `g=0` 的交线。由于有限采样与直线近似，边界杆只近似等值面；新增短接杆不是论文的球心接触图。周期图的无度一节点和连通性不等同于无自交、完整三角化或力学稳定。

## 边界层间腹杆

在三对周期面上，以红蓝跨面桁架节点为端点，按最短距离及空间间距选择额外白色腹杆，拒绝与非共端点已有杆件发生中心线交叉的候选。腹杆端点及整数偏移属于周期图，平移后两侧对应；新增杆件标记为 `boundary-web`。这是工程近似而非论文原始连杆。

应用分别报告新增腹杆与其他非共端点杆件的周期中心线交叉数和胶囊近距离对数。默认参数存在半径范围内的邻近对，部分发生在离散边界曲线的节点附近；不可将其视作无干涉的制造模型。它没有把非共端点附近的杆件自动合并为节点，也没有排除所有节点连接区，须进一步检查与建模。原有白杆之间和原有白杆与所有其他杆件的完整干涉没有验证。增加腹杆不等于证明结构稳定：必须进行周期约束下的刚度矩阵秩/模态及有限元分析。

详细计算和适用范围见 [边界腹杆与刚性分析](docs/边界腹杆与刚性分析.md)。运行 `node tools/analyze.mjs 0.32 0.006` 可输出当前构型的机器可读报告。

## 点阵结构验证

应用右侧检查 2×2×2 周期超胞的图连通性、各相对面中心线几何集合以及 TPMS 标量函数周期性，并支持下载 JSON。测试还覆盖 3×3×3 超胞及断杆负例。它不是自由外边界试件的验证、无限周期刚性证明或全量实体干涉检查。方法、默认结果与限制见 [点阵结构验证](docs/点阵结构验证.md)。

## 力学参数分析

[周期桁架力学参数分析](docs/周期桁架力学参数分析.md) 给出固定胞元、理想球铰轴向杆的周期均匀化方法、w 扫描和局限。安装 `requirements-mechanics.txt` 后运行 `python3 tools/mechanics.py --w 0.32 --tol 1e-12`；这不是梁单元 FEA 或稳定性认证。应用仅内置 w=0.32 的预计算结果，改变 w 需在命令行重新计算。

力学视图提供 w=0.32 的六种应变控制工况下杆轴力和放大变形显示。颜色是 N/EA 而不是实体等效应力；由于内部机构存在，位移图只是一个非唯一的最小范数解。运行 `OPENBLAS_NUM_THREADS=1 python3 tools/mechanics_fields.py` 可重建预计算场，详见力学分析报告第 7 节。
