# 经典力学图鉴 · Mechanics Atlas

一个将原题、公式推演和可交互 3D 演示放在同一时间轴上的中文力学书。目录按 **矢量 → 静力学 → 动力学（含运动学、功与能）→ 质心与惯量** 排列；同类原题可在一个综合演示中切换预设。

> **覆盖尚不完整。** 当前有 36 个综合演示。第一来源的 39 个 Notebook 中有 30 个至少部分关联；第二来源的 14 个 Python Notebook 中有 4 个至少部分关联，另有 14 个 Mathematica 文件尚未逐一解析。关联只代表列出的单元，不代表整本或整个仓库已实现。未关联的题目及已关联文件里的其他题目仍需逐题核对、建模和验证。

- [第一来源覆盖清单](docs/source-coverage.md) · [第二来源覆盖清单](docs/pagonis-coverage.md) · 应用内「源题目录」
- [逐案例 GUI 截图与动态验证画廊](docs/qa/gallery.html) · [机器可读报告](docs/qa/report.json)

## 打开与使用

- 用支持 WebGL 的现代浏览器直接打开 [index.html](index.html)，或打开 [cases/](cases/) 下任一独立案例 HTML。页面内联代码、样式和 KaTeX 字体，不依赖 CDN 或后端；系统仍需要中文字体。源 Notebook 链接需要联网。
- 选择案例，拖动时间轴或点击步骤，同步查看推导、3D 场景和实时读数。手动模式在每步结束时暂停，自动模式连续播放。可旋转、缩放场景；更改参数或同类原题预设后保持相对进度。
- 点击公式下的彩色标签可突出对应场景元素；点击场景标签可反向定位。来源弹窗列出固定提交与具体单元，并可导出当前参数和采样数据的 JSON。
- 键盘：空格播放/暂停，左右方向键切换步骤，`R` 重置。

### 需特别注意的题图、源码与假设

- **悬臂梁**：两份原题图的 6 kg 载荷在 `4b` 梁端，源码却写在 `2b`。默认按题图得到 `R_A=0`、`R_B=90 N`；另一预设按源码位置得到 `40 N`、`50 N`。若参数使单向支座所需反力为负，页面标为无法保持接触，不模拟梁脱离后的运动。
- **A 到 B 的汽车**：题图给 `v₀=10 m/s`、`a=2 m/s²`、`D=20 m`，源码输出却忽略加速度。本演示按题图求出 `t=3√5−5 s`、`v_B=6√5 m/s`；也提供源题匀速预设。Pagonis 例 1.4 给出速度积分条件，本演示进一步积分得到位移，汽车装置是示意。
- **80 m/s、30° 斜抛**：数值来自用户提供的 [截图](references/user-provided-images/image-3.png)，在固定版本 Notebook 中未定位到完整原题；截图未给 `g`，因此演示明确假设 `10 m/s²`。跑者接球预设则直接关联第一来源 `02C1` 的具体单元。
- **三角形重心**：题图的 `B` 表示半条边，而源码计算按整条边；两个预设分别呈现，不能混作同一个结果。
- **圆环双球**：按题图的等半径接触几何，两个球心对应的圆心角为 120°；源代码的法线角不同，页面按题图重新平衡并说明。
- **其他差异**：追车题面加速度 1.5 与源码 0.6 不同；撞墙源码只求 `xmax()`，弹性反射是按图示补充；外力动滑轮和球与圆柱采用题图几何重新列方程。各页面的「查看来源与说明」提供具体假设和单元。

## 文件结构

- `app/src/lessons.js`：有序目录、参数、步骤、公式和来源映射。
- `app/src/models.js`：纯模型；物理状态、读数和事件由同一归一化进度采样。静力学页面进度表示讲解过程，不代表真实时间。
- `app/src/scene.js`、`main.js`：Three.js 场景、标签和同步交互。模型解析求解，均匀杆使用固定步长 RK4 预计算；无需服务端。
- `app/data/source-catalog.json`、`pagonis-catalog.json`：两份固定版本的来源文件与单元元数据。
- `cases/*.html`：自包含案例页；`data/cases/*.json`：默认参数、双来源、步骤、事件和 241 个确定性采样状态。元数据多行排版，每个采样状态一行。
- `docs/qa/`：每案例步骤截图、动态预览、画廊和机器可读报告。
- `references/user-provided-images/`：本轮用户提供的四张题目截图；`references/` 中还保留任务、验收说明及旧版参考。

生成页面提供 `?render` 确定性模式及 `window.seek(t)`；`t` 使用案例的物理时间单位（两船为小时，其余运动案例为秒；概念演示使用自身时间轴单位）。JSON 中保留 `sourceCommit` 作为第一来源兼容字段，并提供完整 `sourceCommits` 和每条来源自己的仓库及提交。

## 开发、构建和验证

需要 Node.js 20.19+（或 22.12+）及 npm：

```bash
npm ci
npm run dev             # 0.0.0.0:5173
npm test                # 物理模型、边界与来源单元检查
npm run build           # 更新根页、cases/、data/cases/ 和两份来源清单
npm run qa:gui          # 基于已构建页面重建 docs/qa/
```

GUI 验证需要 ImageMagick 的 `convert`、`tar`、中文字体及 Chromium 系统库。脚本使用 Playwright 和 `@sparticuz/chromium`，精简 Linux 环境下尝试解压包内 NSS/NSPR 库；中文缺字时请安装中文字体并配置 fontconfig。

本版为 36 个案例保存了 **144 张步骤截图、21 张预设截图和 36 个 17 帧 GIF**。自动验证包括离线打开每个独立页、双来源链接及 JSON 导出、步骤/高亮/仪表同步、参数极值和进度保持、绳长及接触几何、抛体轨迹缓存与位置、播放及移动布局。每案例还以 0.1 秒间隔采样 141 个 WebGL 帧，通过缩略像素差寻找突变；该启发式和压缩 GIF 不等同于人工逐帧审查或完整实时视频。

## 当前限制

- 两个来源均有大量未实现或未逐题核对的题目，第二来源的 Mathematica 文件尤其仍待解析。具体状态见两份覆盖清单，不以文件级关联冒充整本完成。
- 使用程序化教学模型，并未实现任务提示中的物理翻页弯曲、通用剖切/爆炸视图、双渲染风格切换或 SymPy 后端。尺寸缩放、质点、理想绳/滑轮、静动摩擦相等等假设以各案例说明为准。
- 物理残差和参数测试仅针对已建模型及所列参数范围，不证明上游所有题目均已正确复现。
