# 经典力学图鉴 · Mechanics Atlas

一个将原题、公式推演和可交互 3D 演示放在同一时间轴上的中文力学书。目录按 **矢量 → 静力学 → 动力学（含运动学、功与能）→ 质心与惯量** 排列，同类题可在一个演示中切换预设。

> **当前覆盖尚不完整。** 已实现 23 个综合演示，其中部分演示包含多组源题；它们只关联上游 39 个 Notebook 中 23 个文件的部分单元。其他文件及已关联文件中的其他题目仍需逐题核对、建模和验证，不能将本版本视为全部原题复现。详见 [Notebook 关联清单](docs/source-coverage.md) 和应用内“源题目录”。

## 打开与使用

- 直接用支持 WebGL 的现代浏览器打开 [index.html](index.html)，或打开 [cases/](cases/) 下任一独立案例 HTML。每个 HTML 都内联运行代码、样式和字体资源，不依赖 CDN 或后端；系统仍需要支持中文的字体。源 Notebook 链接需要联网。
- 左侧选择案例；拖动时间轴或点击步骤，同步查看推导、3D 场景和实时读数。手动模式在每步结束时暂停，自动模式连续播放。可拖动场景旋转、滚轮缩放；更改参数会重新求解并保持相对进度。
- 点击公式下的彩色标签可突出场景中的对应元素；点击场景标签可定位到相关步骤。顶部提供文字版和来源说明；来源弹窗可导出当前参数的 JSON。
- 键盘：空格播放/暂停，左右方向键切换步骤，`R` 重置。

## 已实现案例

| 顺序 | 综合演示 |
| --- | --- |
| 矢量 | 三维矢量合成（5 组源题预设）；方向与大小确定矢量 |
| 静力学 | 双载荷梁；斜拉绳与临界摩擦；靠墙梯子；球与圆柱接触平衡 |
| 动力学 | 汽车追卡车；列车通过隧道；两船最近距离；变速与折返；水平加速度抛体；抛物线越障；墙面弹性反射；推力与摩擦；斜面摩擦；双斜面滑轮；定/动滑轮；受外力的动滑轮；斜坡与摩擦制动；释放的均匀杆 |
| 质心与惯量 | 五质点质心；圆锥质心；圆盘转动惯量 |

每个演示的来源按钮列出固定版本的 Notebook、**从零开始**的单元索引和 cell ID，也说明源题数值、示意参数及简化假设。源仓版本为 [`dc05f371ac47fb82f9a00f622a274c5433629018`](https://github.com/aldotb/Solve-classic-mechanics-problems-with-python/tree/dc05f371ac47fb82f9a00f622a274c5433629018)。

几处有意披露的源题差异：

- 汽车追赶：题面加速度为 1.5 m/s²，源代码实际用 0.6 m/s²；默认遵循代码，可调回题面值。
- 墙面反射：源代码只调用 `xmax()`，没有模拟碰墙；本页按题图的弹性反射条件独立计算。
- 有外力的动滑轮：源代码中的重力方向和加速度约束与图示不一致；本页按图示重新列力和绳长方程。
- 球与圆柱：题图水平绳与圆柱顶部相切并通过球心，几何关系为 `sin α = R/(R+r)`；源代码使用了 `r/R`。默认按题图得到 24 N，而非源代码的 `9√5 N`。

## 文件结构

- `app/src/lessons.js`：有序目录、参数、步骤、公式和来源映射。
- `app/src/models.js`：纯模型；物理状态、读数和事件由同一归一化进度采样。静力学页面的进度表示讲解过程，不代表真实物理时间。
- `app/src/scene.js`、`main.js`：Three.js 场景、标签、同步控制和交互。模型解析求解，均匀杆使用固定步长 RK4 预计算；无需服务端。
- `app/data/source-catalog.json`：固定版本的 39 个上游 Notebook 和 cell ID 索引。
- `cases/*.html`：每案例自包含页面；`data/cases/*.json`：默认参数、来源、步骤、事件和 241 个采样状态。
- `docs/qa/gallery.html`：每案例的步骤截图和动态预览；`docs/qa/report.json`：机器可读报告。
- `references/`：任务与验收说明及旧版参考；旧版不是本次源题覆盖的依据。

生成页面提供 `?render` 确定性模式及 `window.seek(t)`；`t` 使用案例的物理时间单位（两船案例为小时，其余运动案例为秒；概念演示使用自身时间轴单位）。浏览器导出的 JSON 包含 `timeUnit`、事件、步骤与采样数据。

## 开发、构建和验证

需要 Node.js 20.19+（或 22.12+）及 npm：

```bash
npm ci
npm run dev             # 0.0.0.0:5173
npm test                # 物理模型与来源单元检查
npm run build           # 更新根页、cases/、data/cases/ 和来源清单
npm run qa:gui          # 基于已构建页面重建 docs/qa/
```

GUI 验证还需要 ImageMagick 的 `convert`、`tar`、中文字体以及 Chromium 所需的系统库。脚本使用 Playwright 和 `@sparticuz/chromium`；在精简 Linux 环境中会尝试解压包内 NSS/NSPR 库。若中文缺字，请先安装中文字体并配置 fontconfig。

[验证画廊](docs/qa/gallery.html) 为当前每个案例保存 4 个步骤中点截图及 17 帧压缩 GIF，并保存矢量预设截图。自动检查包括离线打开每个案例、步骤/高亮/仪表同步、参数极值和进度保持、三个滑轮的可视化绳长、球与圆柱接触、播放与移动布局。每案例还按演示时间每 0.1 秒采样 WebGL 帧，使用缩略像素差查找突变；这是一种启发式检查，不等同于人工逐帧审查或完整实时视频。

## 当前限制

- 上游还有大量未实现或未逐题核对的题目，尤其是未关联 Notebook 及已关联 Notebook 的其他单元；[来源清单](docs/source-coverage.md) 不把文件级关联当作整本完成。
- 当前使用程序化示意模型，并未实现任务提示中的物理翻页弯曲、通用剖切/爆炸视图、双渲染风格切换或 SymPy 后端。尺寸缩放、点质量、静/动摩擦相等等假设以各案例说明为准。
- 物理残差和参数测试针对已建模型及所列参数范围，不能证明上游所有题目均正确复现。
