# PLA / ABS / PC 刚接连续梁周期有限元模型

## 使用范围与关键警告

本模型是在应用**当前近似杆图**上建立的三维线性梁有限元，不是实体有限元，也不是论文图 4 的原始硬球接触结构。它包括此前额外添加的单胞面边界框架和腹杆；这些杆不是论文提供的原始数据。当前新增腹杆存在有限杆径邻近警告，杆件和节点实体尚未做完整布尔融合或全量周期实体干涉检查。材料参数也只是示例，因此下面的数值**不能作为制造、承载、稳定或论文复现的认证**。

## 1. 材料、截面和节点的明确假设

| 示例材料 | 弹性模量 E | 泊松比 ν | 剪切模量 G=E/[2(1+ν)] |
|---|---:|---:|---:|
| PLA | 3.5 GPa | 0.36 | 1.287 GPa |
| ABS | 2.0 GPa | 0.35 | 0.741 GPa |
| PC | 2.3 GPa | 0.37 | 0.839 GPa |

这些是为比较而**自行假设的线弹性、各向同性示例值**，不是某种牌号、供应商数据或用户打印件的实测结果。FDM 打印的层间性能、孔隙率、填充、温度和含水率均可能导致明显差异；PLA、ABS 和 PC 还可能表现出蠕变、率依赖、塑性等，本线性模型均未覆盖。实际设计应使用材料实测数据和打印方向相关的本构。

默认参考胞元边长 `a=100 mm`，每根杆均为**实心圆截面**，半径 `r=0.006a=0.6 mm`，直径 1.2 mm。几何性质 `A=πr²≈1.131 mm²`，`Iy=Iz=πr⁴/4≈0.1018 mm⁴`，`J=πr⁴/2≈0.2036 mm⁴`。对于相同 `r/a` 的线弹性周期模型，等效模量与 a 的绝对长度无关，但强度、屈曲、制造限制不能只由此推断。

**连接形式：图中每个共同节点完全刚接**。各相接梁共享三个平移和三个转动自由度；跨周期单胞连接也共享周期位移与转动。包括人工边界轮廓采样点在内的所有图节点均按刚接梁节点处理。这是明确的理想化假设，**不是已经设计完成的实体节点**；不同单元相交但图中不共节点时不会自动连接。对比面板中的旧模型是球铰、仅承受轴向力的杆模型，两者结果不可混用。

## 2. 有限元与边界条件

- 每个元素是 12 自由度三维 **Euler–Bernoulli 梁**，包含轴向拉压、两个方向弯曲与 Saint-Venant 圆截面扭转；不包含横向剪切变形，不是 Timoshenko 梁，也未建节点实体。
- 单胞使用原始杆图中的整数周期偏移。六个工况分别施加 `εxx, εyy, εzz, γyz, γxz, γxy` 单位宏观应变，节点平移波动与转动波动为周期函数。宏观应变使用对称应变张量，工程剪切 `γij=2εij`。
- 为移除整体平移，仅固定基准节点三个平移波动分量；其三个转动仍自由。用稀疏直接求解并由各梁总应变能构造 `6×6` 宏观刚度。加载为线弹性、小位移、无预应力。
- 结果的 `Ex` 由宏观柔度矩阵计算，采用 x 方向应力加载且其他宏观应力为零；`C44` 是固定其余宏观应变下的 yz 工程剪切刚度。显示的三维工况为**指定单项宏观应变 1%，其余宏观应变为零**，并非上面的横向自由单轴应力实验。

## 3. 默认示例结果（w=0.32，r/a=0.006）

默认周期图共有 1416 个节点、2952 根梁；扣除 3 个平移后，周期波动系统有 8493 个自由度。以下为对应假定材料值的计算，单位 MPa：

| 材料 | 有效杨氏模量 Ex | C44 | 泊松比 νxy | 最大相对平衡残差 |
|---|---:|---:|---:|---:|
| PLA | 6.722 | 2.893 | 0.33360 | 6.3×10⁻¹⁴ |
| ABS | 3.841 | 1.653 | 0.33360 | 5.8×10⁻¹⁴ |
| PC | 4.417 | 1.901 | 0.33360 | 6.3×10⁻¹⁴ |

结果依赖于本近似几何和所有节点完全刚接的假设。低残差仅说明所建离散线性方程求解达到数值平衡，**不证明几何合理、物理模型正确或真实结构稳定**。测试中的悬臂梁、刚体运动和简单周期正交梁格解析例用于检查单元公式；这也不是实验验证。

以 PLA 为例，固定单胞、去除整体平移后，对静态刚度矩阵做了 k=0 的低端特征值抽查：最小四个约 `2.3053×10⁻⁹`（以程序归一化自由度和 `E=1,a=1` 表示），相应绝对特征残差不超过 `1.2×10⁻¹⁷`。这些是**静态矩阵的坐标依赖数值，不是振动频率**；旋转和平移变量的尺度也影响数值大小。它们仅说明此抽样在数值精度下未显示额外精确零值，不能证明非零波矢、有限试件、屈曲或真实打印结构稳定。

## 4. 边界采样比较与几何限制

PLA、相同 w 和 r/a 下，改变轮廓采样分辨率后重新生成边界图：

| 采样 | 节点 / 梁 | 最短梁长度 / a | Ex / E | C44 / E |
|---:|---:|---:|---:|---:|
| 24 | 984 / 2520 | 0.003210 | 0.0019219 | 0.0008243 |
| 48 | 1416 / 2952 | 0.002230 | 0.0019206 | 0.0008267 |
| 96 | 2280 / 3816 | 0.0000351 | 0.0019234 | 0.0008267 |

三个数值接近，但每次采样会重新构造边界和连接，**不是同一物理结构的规范网格收敛研究**。分辨率 48 时最短单元约 `0.223 mm`，比假定直径 1.2 mm 短；单元短于直径本身并不自动否定梁网格细分，但此处还涉及短接杆、交叉、重叠、复杂节点和人为边界拓扑，无法直接把它们解释成独立、可制造的细长梁。更细采样的极短梁可能产生严重数值条件问题。必须先修正几何和节点拓扑，再做连续梁或实体网格收敛与对照。

## 5. 三维可视化

应用左侧选择“刚接梁 FE”，选择 PLA / ABS / PC 和六种应变工况。预计算仅适用于 `w=0.32`、`r/a=0.006` 的当前图；其他参数会禁用该视图，需命令行重新计算。每根梁的变形曲线使用对应节点位移、转角及 Euler–Bernoulli Hermite 插值绘制；变形倍数可选 0–3 倍，默认 1 倍。线性计算只针对 1% 宏观应变，放大倍数仅改变显示，不是重新计算的大变形。

颜色是梁的 `N/(EA)`：红色拉、蓝色压，**只显示轴向力，不包括弯曲应力、扭转应力，也不是实体 von Mises 云图**。变形后的杆显示在未变形参考盒附近；显示边界是参考状态而非变形域的实体截面。

此前的球铰仅轴向杆模型存在大量机构，其变形图已经撤回；本刚接梁视图是**不同的模型假设**。即便其 k=0 方程可解，也不能认为已完成真实实体、碰撞、强度或屈曲验证。

## 6. 复现和自定义

```sh
npm ci
python3 -m pip install -r requirements-mechanics.txt
# 默认三种示例材料
OPENBLAS_NUM_THREADS=1 python3 tools/frame_fem.py --output data/my-frame.json
# 仅 PLA，修改材料参数、单胞长度和杆半径比
OPENBLAS_NUM_THREADS=1 python3 tools/frame_fem.py --material PLA --E-GPa 3.2 --nu 0.35 --a-mm 80 --r 0.008 --output data/my-pla.json
# 仅固定胞元 k=0 的静态低阶特征值检查（不是振动频率）
OPENBLAS_NUM_THREADS=1 python3 tools/frame_fem.py --material PLA --verify-modes --output data/my-k0.json
# 重建默认展示字段与边界采样比较
OPENBLAS_NUM_THREADS=1 python3 tools/frame_fields.py
OPENBLAS_NUM_THREADS=1 python3 tools/frame_resolution_scan.py
# 解析例、周期梁格、平衡和字段一致性测试
OPENBLAS_NUM_THREADS=1 python3 -m unittest discover -s tests -p 'test_frame_fem.py' -v
```

默认三材料报告、k=0 抽样、可视化字段和边界采样报告分别在 `data/frame-fem-default.json`、`data/frame-fem-k0-pla.json`、`data/frame-fem-fields-w032-r006.json`、`data/frame-fem-resolution-scan.json`。自定义命令的结果不会自动写回应用预计算视图。

下一步应取得论文双层实际点/边或复现其 MC，定义真实节点尺寸和材料打印方向；修复实体重叠后，使用实体或 Timoshenko/梁-实体对照、周期和自由边界、非零波矢及屈曲/强度分析，并对固定几何做网格收敛。
