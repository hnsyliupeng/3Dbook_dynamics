# 轻量化与压缩吸能：深入分析和数据处理

## 1. 分析对象必须一致

项目现在有两个不同对象，不能把它们的结果拼成一个“比刚度”：

1. **周期刚接梁模型**：100 mm 胞元、杆径 1.2 mm，所有梁节点刚接，假设材料为各向同性线弹性。PLA 假设 E=3.5 GPa、ν=0.36 时，周期均匀化 Ex=6.722 MPa。这是小变形、固定胞元的线性刚度，不包含屈曲、接触、塑性、损伤或压溃。
2. **默认 40 mm 打印 STL**：杆目标直径 1.4 mm、融合杆件、额外增加 12 根立方体棱边框架，并以 0.4 mm 间距采样。它的几何、边界和杆径与梁模型不同。不得使用前者 Ex 除以本 STL 的密度，或把前者变形图当作打印件压溃预测。

默认 STL 的有向三角网格体积为 **10112.288 mm³**，包络盒 40×40×40 = 64000 mm³，因此其**实体几何体积分数** `Vs/V ≈ 0.15800`（15.80%）。见 `data/print-stl-volume.json`。该值是所给网格在近似封闭、方向一致条件下的几何计算，取决于融合、附加框架和采样；它不是实测质量密度。它不包含切片支撑，也不包含打印空隙、非实心路径或制造误差。模型体积可用 `node tools/stl_volume.mjs exports/gyroid-40mm-fdm.stl` 复算；该脚本本身不验证闭合。已有 STL 导出时的边连接检查和独立网格检查，但这不是打印质量认证。

已给定的线性模型不能输出峰值力、强度、平台应力、压溃力效率或大变形吸能。**需要真实压缩曲线，或经验证的非线性计算曲线**；当前没有这些数据，不能声称得到优化后的最优结构。

## 2. 指标和边界条件

下面均针对同一个指定尺寸、材料、打印方向、试验速率、装夹和压缩方向的试件。截断位移 `δ` 必须在有效数据区间内；比较不同试件时应保持**相同工程应变 δ/H**、速率和积分起点。

| 指标 | 定义及本工具方法 | 关键注意事项 |
|---|---|---|
| 相对密度 | 试验密度法 `ρeff/ρsolid = (m/V)/ρsolid` | V 是初始包络体积，m 是去除支撑后的试件实测质量；ρsolid 应来自同材料的实测基体。它和 CAD 的 `Vs/V` 因打印孔隙不同不一定相同。 |
| 刚度 E | 用户选定应变窗口的 `(σ₂−σ₁)/(ε₂−ε₁)` | 这是窗口割线，不自动代表初始弹性模量；试验机柔度、初始就位、端面摩擦会影响结果。 |
| 比刚度 | `E/ρeff` | 与几何分数不同，ρeff 有单位；工具单位是 `MPa/(g/cm³)`。窗口和方向须一致。 |
| 峰值压应力 | `max F / A0`，从 u=0 到 δ | 是指定范围的工程应力峰值，不等同材料强度或可重复承载能力。A0 为初始受压投影矩形面积。 |
| 比峰值强度 | `(max F/A0)/ρeff` | 同上，并受样品质量、尺度与方向影响。 |
| 吸能 EA | `∫₀^δ F(u)du`，以梯形法积分 | 本文 EA 指能量，不是轴向刚度 E×A。N·mm 除 1000 得 J；不外推数据。 |
| 比吸能 SEA | `EA/m` | 本工具输出 J/g，数值等于 kJ/kg；应报告积分终点。 |
| 压溃力效率 CFE | `(EA/δ)/Fpeak` | 平均力和峰值都取相同 `[0,δ]`，0≤CFE≤1（压力非负）。若峰值为零，则未定义。 |
| 平台应力 | 用户选定窗口的 `∫ F du / (Δu A0)` | 软件不自动识别平台或致密化。只有曲线确实存在平台时才应这样解释，并记录窗口；不等同全程平均应力。 |

截断点及窗口边界若不恰好是测点，按相邻测点线性插值。力为压缩正值，位移从接触校正后的零点开始严格递增；重复位移、卸载循环、负值、未覆盖范围均拒绝，需先自行预处理并记录方法。对于断裂、噪声较大的离散数据，试验采样率与滤波会影响峰值和积分；不可隐去原始数据及处理参数。空白刚度或平台窗口输出“未指定”。

## 3. 使用页面数据处理

打开页面“压缩吸能分析”，导入 UTF-8 CSV，严格使用表头与两列 `u_mm,F_N`，例：

```csv
u_mm,F_N
0,0
1,10
2,20
3,10
```

上面只是**算法示例，不是本结构的试验数据**。录入受压宽度、深度、初始高度、去支撑后质量；如需相对密度再录入同材料实测基体密度。可设置截止位移，并可手动输入刚度与平台的工程应变起止（小数，0.10 表示 10%）。点击计算后显示力–位移曲线、所有可计算指标及截断线，下载 JSON 含输入数据和参数。数据仅在浏览器本地处理，不传给服务器。

受压面积用 `宽×深`，工程应变用 `位移/初始高度`。质量必须是试件本体的实测质量；支撑、底座是否计入须保持一致。本工具不校正机器柔度、初始接触段、压头摩擦、试验机惯性或真实试件的非矩形投影；需在输入前处理或通过更合适的测量方法解决。

## 4. 面向优化的可执行路线

1. **定义约束与设计变量**：明确成型空间、最小可打印杆径、去支撑方式、可接受峰值载荷、目标压缩行程、质量上限、方向和重复性。变量可包括 w、各类杆截面、跨层腹杆位置、单胞数及边框。注意 STL 中的边框与融合占材并改变响应；应为每种设计重新检查有效几何，不能沿用同一 FE 结果。
2. **几何筛选**：针对每个候选导出真实融合网格，计算 `Vs/V`、连通、局部最小厚度、碰撞/节点融合、可切片性和支撑可拆除性。现在仅对默认 STL 计算了体积分数，尚无网格尺度收敛或全量最小厚度验证。
3. **小变形筛选**：只在同一几何和材料假设下，以合适的边界条件求线性刚度和模态；对打印实体需重新建模，不得把周期梁模型当有限试件。对质量归一时使用同一模型的实体体积和材料密度。
4. **非线性压缩**：若要预测峰值与吸能，需要实体或经校准的梁–接触模型，包含几何大变形、杆件自接触/压头接触、材料非线性、必要的损伤与层向异性，指定压缩速率、摩擦和端面边界；验证质量、能量平衡、网格、接触与步长敏感性。线弹性梁外推无法替代此步骤。
5. **实测校准与多目标比较**：对材料和打印方向制作试样，称重、量尺寸、压缩，保留力–位移原始记录；对同一截止应变计算 SEA、CFE、峰值应力和密度，记录均值、离散度与失败模式。筛选满足质量、峰值、变形及制造约束的候选，再对比 SEA、比刚度等，形成 Pareto 前沿；不能只最大化 SEA 而忽视过高峰值或不可拆支撑。具体重复次数与加载工况应按项目可靠性要求制定。

用户可提供真实 CSV、初始长宽高、去支撑后试件质量、基体密度、压缩方向/速度与目标截止应变；再对本结构给出可复核的数值结论。不同材料 PLA、ABS、PC 的实测性能不能仅靠当前假设的三个弹性模量推算。
