# 边界破片：排查和当前限制

用户指出 DLP 参考参数 `a=14 mm`、`r=0.45 mm`、`w=0.32`、`2×2×1` 的画面有大量破片。不能把它们一概当成真实物理碎片，也不能仅凭截图认定全部是渲染瑕疵。本次发现并修复了两处显示问题：

1. 对每个图杆，原来把进入每个小胞元窗口的周期像重复加入大阵列；相邻胞元会多次绘制同一位置的同一根杆，导致重合表面的深度竞争。以该参考参数为例，旧逻辑绘制 20400 个圆柱实例，其中 3152 个为同一图杆和周期平移的重复实例。现按图杆和整阵列平移向量去重。
2. 原显示为容纳圆截面，连**中心线完全在窗口外**但圆截面与窗口相交的杆也进行剪裁。这些周期邻胞圆柱可能只留下一小块表面。新预览只显示中心线与外窗口相交且有非零长度的杆，并继续使用同一外边界裁剪圆柱。它是明确的**中心线预览策略**：如果中心线完全在外，有限杆径伸入窗口的实体部分不显示。因此它不是有限域实体精确截面的证明，也不应拿来检验可打印性。

现有截图 `dlp-fragment-fix-045.png`、`dlp-fragment-fix-030.png` 用浏览器验证了参数切换、窗口绘制和告警。去重减少了重复实例，但**截图仍存在粗糙和片状显示，问题尚未彻底解决**。当前每条杆仍是独立圆柱，边界曲线由很多短杆构成，裁剪面没有实体布尔封口；杆件及节点真实重叠也可能产生交叉表面。不能由本次修正声称杆实体已经融合、边界光滑或不存在孤立小片。

参考参数 r=0.45 mm 本身也已检查到红蓝杆相互重叠，最小净距约 -0.176 mm；r=0.30 mm 时已检查红蓝杆对净距约 +0.123 mm，但不覆盖全部实体、跨层杆和节点。最终需构造参数一致的 DLP 阵列实体，将各杆和节点做可靠布尔融合，修正短杆及局部不合理拓扑，验证裁剪面封闭、连通、非流形与最小厚度，并用切片器和实体网格截图核查。现有 FDM STL 不随 DLP 阵列参数变化，本次没有声称生成了匹配 DLP 的打印文件。

自动测试 `node tests/visual-copies.mjs` 检查 1³、2×2×1、2³ 显示复制无重复、显示杆中心线与窗口相交，并检查节点副本不重复；它不改变或认证原周期图拓扑、物理实体、力学或打印能力。
