# 桁架体素融合预览：针对边界破片

之前的独立圆柱显示在边界截面和高密度短杆处有大量破片状表面，即使周期副本去重后仍然明显；这不能算解决。现在提供“体素融合预览（近似）”和“独立杆件（原始对照）”两种结构视图，DLP 面板中可切换。选前者时，浏览器后台根据当前周期杆中心线、杆半径和数组生成**一个近似体素融合外表面**，不再把每个相交杆的独立圆柱面叠在一起。对照视图则为被边界平面裁剪的独立杆件，补画了截面以减轻裸露裁口，仍可能有重叠和深度伪影。

融合预览是可视化近似：

- 首先将当前显示窗口中中心线有非零长度的周期杆复制作为胶囊，采样其与窗口的交集，再以固定分辨率的 surface nets 提取外表面。没有保留中心线完全在窗口外但横截面伸入的杆；胶囊端部也不同于原来的平端圆柱。视图不是精确的布尔实体或全部有限截面周期像的截断。
- 每根杆在交叠处融合为单一外表面：同层、白色跨层杆以及**意外相交的红蓝层也会融合**。颜色是由附近杆件归属着色，不能据此证明层间无干涉；该预览可能改变可见拓扑、抹去间隙或细杆。不允许把融合画面当成物理无碰撞验证。
- 默认参考 `a=14 mm, 2×2×1` 的视图网格间距约 0.194 mm。r=0.45 mm 时直径约 4.6 格；r=0.30 mm 时直径约 3.1 格。此分辨率仅适合粗略显示，并不能代替网格收敛或打印最小特征检查。小于 3 格会明确警告细杆可能失真或缺失。
- 曲面是近似单一显示网格，不保证网格流形、封闭、结构连通或最小厚度，不可作为 STL 或力学模型。现有 STL 导出仍是独立 FDM 单胞，与这里的 DLP 数组和尺寸无关。
- 交互修改后会取消旧后台任务并重算；等待状态结束再查看。较多胞元会明显消耗 CPU 与内存。

浏览器截图 `dlp-union-preview-045.png` 和 `dlp-union-preview-030.png` 展示了参数一致的融合预览，相比原始独立杆视图，重合面造成的破片状显示明显减少；实际几何仍有密集重叠。0.45 mm 示例已检查红蓝最小净距为负，因此融合可掩盖真实碰撞；0.30 mm 的已检查杆对净距为正也不涵盖全部实体和工艺条件。当前不能据此保证打印可行或完成论文原始拓扑重建。

应进一步生成与参数匹配的高精度实体模型，保留设计意图的层间关系，处理短杆和交叉，按 DLP 实际树脂/设备独立校核，并进行流形、闭合、最小截面、可清洗及切片检查；需要重新对该实体进行有限元与实验验证。可使用 `node tests/preview-union.mjs` 检查有界测试场，`node tests/visual-caps.mjs` 检查原始杆显示截面；这些测试不构成实体或打印认证。
