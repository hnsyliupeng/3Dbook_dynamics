# 周期双层 Gyroid 桁架：线性力学参数分析

## 1. 结论与范围

对应用当前**近似**周期杆图，完成了固定胞元周期位移条件下的六个宏观小应变工况，计算理想轴向桁架的等效刚度。默认构型的宏观刚度矩阵是正定的，但其图中存在大量内部机构：**宏观均匀化矩阵正定不等于整体机构刚性、动态稳定或可制造性通过**。

本结果不是论文图 4 的真实结构参数，也不是梁单元有限元或实验值。模型包含本应用附加的单胞边界轮廓杆与白色腹杆；这些杆件不是从论文双层原始数据恢复的。

## 2. 模型和计算方法

- 单胞边长 `a=1`；各杆材料、截面相同，轴向刚度 `EA=1`。节点按理想球铰处理，每根杆只有轴向拉压刚度 `EA/L`。
- 局部自由度是节点周期位移，首个节点的三个位移只用于去除整体平移。微观波矢为零；小应变宏观形变在胞元上通过仿射项施加，胞元内部位移可以周期松弛。计算时未约束其他内部机构。
- 周期边 `(i,j,o)` 的杆向量 `d=xj+o−xi`，其中 o 是整数胞元平移，杆长 `L=|d|`，单位方向 `n=d/L`。施加宏观应变张量 ε 时，杆轴向伸长为 `n·(uj−ui+εd)`，杆能量为 `½(EA/L)[n·(uj−ui+εd)]²`。
- 六个独立工况的应变向量为 `[εxx, εyy, εzz, γyz, γxz, γxy]`，工程剪应变 `γij=2εij`。通过 SciPy LSMR 对周期波动位移求最小能量，汇总 6×6 等效刚度 `C`，满足单位胞元能量 `½eᵀCe`。结果统一以 `EA/a²` 为单位；无松弛纯仿射刚度作为上界也保存于 JSON。
- 不包含抗弯、扭转、刚接或真实节点实体、初始应力、屈曲、塑性、大变形、接触与制造公差；未考虑非零波矢、有限试件自由边界或损伤。所有杆的 EA 一致，未计重复杆材重叠或实体熔合。

## 3. 默认结果（w=0.32，包含边界腹杆）

胞元图含 1416 个节点、2952 条杆，最短杆约 0.00223a。归一化刚度矩阵（对称，按上面工程剪应变次序）：

```text
C / (EA/a²) ≈
[24.569611  12.410988  12.410988   0         0         0       ]
[12.410988  24.569611  12.410988   0         0         0       ]
[12.410988  12.410988  24.569611   0         0         0       ]
[ 0          0          0          6.954145  0         0       ]
[ 0          0          0          0         6.954145  0       ]
[ 0          0          0          0         0         6.954145]
```

以 `C⁻¹` 得到沿胞元 x、自由横向应力为零条件下的等效杨氏模量 `Ex = 16.239154 EA/a²`，泊松比 `νxy = 0.335608`。约束其余宏观应变时 `C44 = 6.954145 EA/a²`；均匀体积应变对应体积模量 `Kε = 16.463862 EA/a²`。这些是方向性参数，不应自动假设为完全各向同性；计算中 C 的六个特征值约为 `6.9541`（三重）、`12.1586`（二重）、`49.3916`。

如果各杆是半径 `r` 的圆截面、弹性模量为 `Es`，则 `A=πr²`，形式换算为 `Ex/Es=16.239154 π(r/a)²`。例如 **仅作为量纲示例**，若 `r/a=0.006` 且 `Es=1 GPa`，该理想模型给出 `Ex≈1.84 MPa`；改变截面或不同杆材须重新建模。实际重叠、节点尺寸、材料和屈曲可能使这一数值不适用。

## 4. w 参数扫描与腹杆贡献

| w | 边界腹杆数 | Ex/(EA/a²) | νxy | C44/(EA/a²) | Kε/(EA/a²) |
|---:|---:|---:|---:|---:|---:|
| 0.15 | 31 | 14.250329 | 0.362859 | 6.327154 | 17.318281 |
| 0.32 | 24 | 16.239154 | 0.335608 | 6.954145 | 16.463862 |
| 0.50 | 24 | 12.921606 | 0.341344 | 4.657446 | 13.573988 |

w 为隐式函数的等值偏移，不是精确层间法向距离。各行重新生成了节点和连边，杆拓扑也可改变，因此这三点不是固定拓扑的连续灵敏度分析，也不能据此确定最优值。`EA` 归一化下的结果不依赖可视化半径；圆截面假设下可再按上式缩放，但不检查改变半径后的碰撞。

对这三个构型，分别移除新增边界腹杆、保持其余图不变后，6×6 宏观矩阵的最大分量差均不超过约 `2×10⁻¹⁴ EA/a²`；新增腹杆在六个已松弛工况中的能量占比小于 `8×10⁻²²`（数值精度范围）。也就是说，**当前模型与这些周期均匀应变工况下，新增腹杆几乎没有贡献宏观轴向刚度**；这并不证明其对局部荷载、梁弯曲、有限边界或非零波矢毫无作用。

## 5. 机构与数值核查

此前的固定胞元铰接杆系自由度计数给出默认构型至少 **1293 个非平移无穷小机构**，其中有 684 个度为 2 的节点；这是机构数下界，不是完整求秩结果。边界曲线采样点均视作球铰造成大量局部自由度；如果实际是连续梁或刚接件，必须使用不同模型。宏观 C 虽然正定，仍可能与这些内部零能运动同时存在。

- 六个 LSMR 工况均达到求解停止条件；`tol=1e-12` 时，默认工况的归一化法方程残差不超过约 `1.2×10⁻¹⁰`。
- 与 `tol=1e-10` 的重复计算比较，默认矩阵最大绝对差约 `9.3×10⁻¹⁴ EA/a²`。这些是收敛核查，不是模型误差或实验误差。
- 测试包含单位胞元三正交杆的解析解、刚度对称性与半正定性、增加杆件不降低松弛能量的数值检查。
- 本分析没有验证全部白杆和节点实体的干涉。现有几何检查在默认参数仍报告 144 对新增边界腹杆的有限杆径邻近，须在工程使用前处理。

## 6. 复现与下一步

```sh
npm ci
python3 -m pip install -r requirements-mechanics.txt
OPENBLAS_NUM_THREADS=1 python3 -m unittest discover -s tests -p 'test_mechanics.py' -v
OPENBLAS_NUM_THREADS=1 python3 tools/mechanics.py --w 0.32 --tol 1e-12 --output data/my-mechanics.json
```

完整矩阵、纯仿射上界、六个求解状态、残差、边界腹杆能量份额分别保存于 `data/mechanics-default.json`、`data/mechanics-w015.json`、`data/mechanics-w050.json`。程序接受 `w=0.15…0.50`；如果 LSMR 未收敛，`converged=false`，不应使用该结果。

下一步需要明确真实材料、尺度、杆截面和节点连接形式；将轮廓采样点合并为连续梁或采用梁单元；先做完整周期实体干涉，再做周期刚度矩阵秩、非零波矢模态、屈曲和有限元计算。若要求论文定量对照，还需图 4 双层原始坐标与真实接触连边或重新实现其硬球 MC。

## 7. 三维轴力与变形可视化

应用左侧选择“轴力与变形”，可切换六个工况。每个工况是**单个指定宏观应变分量为 1%，其余宏观应变分量为零**；这是应变控制，不是横向零应力的单轴拉伸试验。工程剪切分量为 γ，而不是张量剪切分量 ε。对应 `w=0.32` 的预计算场，改变 w 后视图自动禁用；字段与节点、边及周期偏移逐一校验。

红色为拉力、蓝色为压力、灰色附近为小轴力。色标值是归一化轴力 `N/EA`，不是实体 von Mises 应力；色标两端对应该工况 1% 应变下的对称最大绝对值。杆轴向力按 `N/EA = ΔL/L` 计算，截面与材料均匀，并非每根杆的三维应力分布。

变形图是在未变形胞元中裁切杆中心线后，将端点按计算出的周期节点位移和宏观仿射变形移动；灰细线为参考位置。默认显示放大 5 倍，因而视觉形变大于 1% 工况的真实线性位移。显示框仍是未变形参考单胞，变形后杆件可以超出它。杆颜色始终对应 1% 工况，不随变形显示倍数改变。模型存在大量机构，节点位移解并不唯一；图中显示固定首节点、LSMR 给出的一个最小范数周期波动解，**不是预测的唯一真实变形形态**，也不证明结构稳定。

生成场及核查：`OPENBLAS_NUM_THREADS=1 python3 tools/mechanics_fields.py`；测试 `python3 -m unittest discover -s tests -p 'test_mechanics*.py'` 检查图拓扑一致性、每根杆的轴向结果、平衡法方程残差，以及场重建的六工况刚度矩阵与汇总报告一致。
