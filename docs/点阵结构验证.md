# Gyroid 双层桁架：周期点阵验证

## 范围

验证对象是当前应用生成的近似周期图（包括额外边界轮廓杆和腹杆），而非论文图 4 的原始双层结构。坐标和长度以胞元边长 a 为单位。每条无向杆 `(a,b,o)` 连接基准胞元的节点 a 与平移了整数向量 o 的节点 b。2×2×2 图的外表面再次按周期条件识别；这不是具有自由外边界的 8 胞元试件。

## 默认参数结果

`w = 0.32`，`r = 0.006a`，等值线分辨率 48。运行 `node tools/analyze.mjs 0.32 0.006` 可重算，调整参数后结果可能改变。

| 验证 | 结果 | 含义 |
|---|---|---|
| x/y/z 对面中心线匹配 | 每轴均 380 个不同截点、356 条不同面内杆线段；不匹配数均为 0 | 平移 + 面后，对红、蓝、白杆分别比较截点和面内线段集合，坐标量化步长 1e-7a，允许相邻量化格；截点沿面内两个方向按周期识别；集合比较不验证重数和实体截面 |
| 2³ 周期图 | 11328 个活动节点、23616 根周期杆，整体 1 个连通分量 | 逐条使用边的整数周期偏移复制 8 个胞元；包括附加边界框架 |
| 2³ 红 / 蓝子图 | 各自 5664 个活动节点，各有 1 个连通分量 | 忽略另一颜色及跨层杆，针对有同层杆的活动节点；不是实体连续性或力学刚度 |
| 3³ 周期图 | 38232 节点、79704 杆，整体 1 个连通分量 | 是进一步有限超胞测试，不能仅凭这两个尺寸证明任意尺寸的连通性 |
| Gyroid 对面取值 | 每个方向采样 21×21 点，最大误差约 4.44×10⁻¹⁶ | 检查标量函数 f 的周期性；±w 等值面随之周期，非三角网格或实体模型的几何误差 |

比较一对邻接单胞时用正面和另一单胞负面的几何集合，测试中人为删除一根边界杆后可检测到不匹配。此外，特意构造只沿 x 连接的测试图，在 1³ 周期图连通但 2³ 图不连通，以避免仅凭单胞连通判断点阵连通。

上述面匹配对于用同一个周期图平移产生的点阵主要验证程序中的偏移、裁切与坐标一致性；不能证明原始论文拓扑正确，也不能证明无限点阵的任意规模、实体碰撞或力学性能。面内线段为集合比较，不验证连接端点的入射重数。超胞图验证不同节点是否由图边相连，不认为空间中相交而无共同节点的杆自动连接。

## 尚未通过或未覆盖的验证

- 原有白色腹杆与全部杆件的**完整周期实体干涉**、节点实体和加工公差未完成检查。默认新增边界腹杆仍有 144 对有限杆径邻近警告；这不是无干涉认证。
- **力学稳定未通过**：固定胞元、球铰、纯轴向杆假设下，机构数下界 1293。见 [边界腹杆与刚性分析](边界腹杆与刚性分析.md)。这不是连续梁或刚接模型的模态数。
- 只对解析隐式函数做周期数值采样；并未证明渲染曲面三角网格与桁架实体之间完全贴合，边界轮廓也只是近似采样。
- 未做无限点阵非零波矢模态、屈曲、材料或载荷计算，也未与论文图 4 的双层原始坐标和杆拓扑定量匹配。

## 操作

应用右侧“点阵拼接验证”显示当前构型的 2³ 结果，并可下载 JSON；左侧可切换 2×2×2 三维展示。命令行运行：

```sh
npm install
npm test
node tools/analyze.mjs 0.32 0.006
```
