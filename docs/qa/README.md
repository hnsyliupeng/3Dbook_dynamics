# GUI 与动态验证

- [逐案例截图及动态预览](gallery.html)
- [移动端截图](mobile-pulley.png)
- [机器可读报告](report.json)

本次针对 57 个已实现综合案例，分别保存 4 个步骤中点截图（共 228 张）和 17 帧 GIF；另有 33 张原题预设截图。所有独立 HTML 直接以 file:// 打开；验证源目录、时间轴、参数最小/中间/最大值、高亮标签可见性、仪表、播放/暂停和移动端横向溢出。七个滑轮/绳索场景额外检查参数极值及各时刻的可视化绳长保持不变；21 个应用装置的全部预设检查组合极值、运动与接触几何、事件时刻及轨迹端点；五张用户题图检查离线加载；压缩案例逐个测试无 render 参数时的滑块、seek 和解压不可用回退。还检查梁、两球、球与圆柱、汽车接触、抛体轨迹缓存/坐标、两个来源的链接与 JSON 导出，以及列车、碰撞和越障事件。

每个案例另外以统一时间轴逐 0.1 秒采样 141 个 WebGL 帧，缩至 240×136 比较像素变化；推演步骤边界的有意高亮变化不计尖峰。该启发式不能替代人工逐帧审查，GIF 也不是完整实时视频。

自动检查未报告标签越界、标签重叠或帧差尖峰。

这些验证只覆盖当前已实现案例，不能视为源 Notebook 的全部题目已复现。

GUI 截图为最多 256 色的索引 PNG（无抖动），尺寸不变；原始题图和动画 GIF 未处理。

另对 57 个案例在非 render 模式下实际播放：确认 requestAnimationFrame 推进模型时间、播放中改参数保留相对进度、暂停后保持不动；连续 100 次暂停/播放后仅存在一个待执行动画帧。详见 [实际播放报告](live-playback.json)。

本轮截图与帧差扫描使用的是播放帧管理修复前的确定性渲染构建；最终构建逐案例比较了全部 228 个步骤中点的状态、文字和 WebGL 画布，结果完全相同。实际播放及离线页使用最终构建验证。详见 [渲染等价比较](render-equivalence.json)。
