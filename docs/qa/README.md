# GUI 与动态验证

- [逐案例截图及动态预览](gallery.html)
- [移动端截图](mobile-pulley.png)

本次针对 23 个已实现综合案例，分别保存 4 个步骤中点截图（共 92 张）和 17 帧 GIF；另有 5 张矢量原题预设截图。所有独立 HTML 直接以 file:// 打开；验证源目录、时间轴、参数最小/中间/最大值、高亮标签可见性、仪表、播放/暂停和移动端横向溢出。三个滑轮场景额外检查参数极值及各时刻的可视化绳长保持不变；球圆柱场景检查接触和水平绳，列车与越障案例检查事件及关键点的可视化位置。

每个案例另外以统一时间轴逐 0.1 秒采样 141 个 WebGL 帧，缩至 240×136 比较像素变化；推演步骤边界的有意高亮变化不计尖峰。该启发式不能替代人工逐帧审查，GIF 也不是完整实时视频。

自动检查未报告标签越界、标签重叠或帧差尖峰。

这些验证只覆盖当前已实现案例，不能视为源 Notebook 的全部题目已复现。
